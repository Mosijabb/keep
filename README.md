# Keep - Personal Relationship Management PWA

A focused, privacy-friendly Personal Relationship Management (PRM) Progressive Web Application designed for staying in touch with the people who matter most.

## 🚀 Features

- **Today / Daily Dashboard**: Quick triage of connections, overdue contacts, upcoming commitments, and open loops.
- **People Directory**: Manage contacts with custom tags, contact cadence/frequency, and relationship history.
- **Quick Logging**: Fast interaction logging with interaction types (call, coffee, message, etc.) and automatic cadence resets.
- **Open Loops**: Track follow-ups, promises, and mutual to-dos.
- **PWA & Offline Capable**: Built with Vite and Service Workers for installability and responsive mobile-first usage.

## 🛠 Tech Stack

- **React 18** with **TypeScript**
- **Vite** for fast modern bundling
- **Tailwind CSS** & **Lucide React** for UI and styling
- **Dexie.js / IndexedDB** for local-first storage
- **date-fns** & **Zod**

## 💻 Development

Install dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
